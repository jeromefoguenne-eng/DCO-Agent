# Compétence : Analyse de Données & Excel (Maxime BI)

## But
Parser les données chiffrées des écoles (fichiers CSV/Excel d'indicateurs de pilotage FWB) pour extraire les données clés, calculer les écarts et produire des synthèses décisionnelles.

## Fonctionnalités
- **Lecture et nettoyage** de tableaux d'indicateurs FWB.
- **Calculs statistiques** : Écarts avec la moyenne FWB, évolutions pluriannuelles.
- **Analyse par groupe de comparaison (ISE N1 à N20)**.
- **Génération de résumés textuels** exploitables dans les rapports DCO.
