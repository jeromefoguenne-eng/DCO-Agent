# Glossaire et Lexique Institutionnel FWB

| Sigle / Terme | Définition Complète |
| :--- | :--- |
| **DCO** | Délégué aux Contrats d'Objectifs (FWB) |
| **PO** | Pouvoir Organisateur (Responsable de la gestion de l'établissement) |
| **CE** | Chef d'Établissement / Direction d'école |
| **FWB** | Fédération Wallonie-Bruxelles (Communauté française de Belgique) |
| **AGERS** | Administration Générale de l'Enseignement et de la Recherche Scientifique |
| **AGFE** | Administration Générale de l'Enseignement Obligatoire |
| **CoPS** | Conseil de Participation de l'école |
| **WBE** | Wallonie-Bruxelles Enseignement (Réseau d'enseignement officiel) |
| **ISE** | Indice Socio-Économique (Echelle N1 à N20) |
| **FASE** | Fichier des Établissements (Numéro d'identification d'une école FWB) |
| **CEB** | Certificat d'Études de Base (Fin de 6e primaire) |
| **CE1D** | Certificat d'Études du Premier Degré de l'Enseignement Secondaire (Fin 2e sec.) |
| **CESS** | Certificat d'Enseignement Secondaire Supérieur |
| **EAL** | Encadrement Adapté et Logistique / Dispositif d'aide |
