# 📄 GRILLE : Évaluation SMART d'un Objectif Spécifique

| Critère | Question d'Évaluation | Évaluation DCO (Validé / À retravailler) | Recommandation DCO |
| :--- | :--- | :--- | :--- |
| **S** (Spécifique) | L'objectif est-il clair, précis et sans ambiguïté ? | | |
| **M** (Mesurable) | Existe-t-il une valeur cible chiffrée ou un critère qualitatif précis ? | | |
| **A** (Atteignable) | L'équipe éducative y adhère-t-elle et les actions sont-elles réalistes ? | | |
| **R** (Réaliste) | Les moyens matériels, temporels et humains sont-ils suffisants ? | | |
| **T** (Temporel) | Des jalons intermédiaires (Année 1, 2, 3) sont-ils définis ? | | |
